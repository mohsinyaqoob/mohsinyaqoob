## 👋 About me

I am a **Frontend Engineer** focused on building production-grade, enterprise software that is accessible, performant, maintainable, and pleasant to use.

My work goes beyond writing UI. I enjoy the full path from **design and architecture to testing, CI/CD, deployment, and production**.

I have experience working with **monorepos, shared design systems, automated pipelines, AWS, Docker, Linux, bare-metal environments, and production deployment workflows**.

I also enjoy building MVPs where speed matters, then evolving them into systems that can survive real users, growing requirements, and production constraints.

> Good software is not just code that works. It is code that can keep working.

## 🤖 AI & agentic development

I use **AI coding tools, Claude, Claude Code, and coding agents** as part of my engineering workflow.

I am interested in agentic development as a **human + agent collaboration**, rather than simply generating code automatically.

```text
Human defines context + constraints
              ↓
        AI explores code
              ↓
       Agent implements
              ↓
       Tests + iteration
              ↓
Human reviews behaviour + trade-offs
              ↓
             Ship
```

The interesting part is not simply writing code faster.

It is learning how to give an agent the right **context, architecture, constraints, and feedback** to work effectively inside a real production codebase.
