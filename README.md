## 👋 About me

I am a **Frontend Engineer** focused on building production-grade, enterprise software that is accessible, performant, maintainable, and pleasant to use.

My work goes beyond writing UI. I enjoy the full path from **design and architecture to testing, CI/CD, deployment, and production**. I have worked with monorepos, shared design systems, automated pipelines, AWS, Linux and bare-metal environments, and the engineering workflows that keep large applications moving.

I also enjoy building MVPs where speed matters, then evolving them into systems that can actually survive real users.

> Good software is not just code that works. It is code that can keep working.

## 🧩 What I care about

- ♿ **Accessibility first**: semantic HTML, keyboard UX, focus, contrast, screen readers and inclusive interaction
- 🎨 **Design to code**: design systems, tokens, color theory, typography, spacing and visual hierarchy
- ⚡ **Performance**: rendering, networking, caching, lazy loading, virtualization and perceived performance
- 🧪 **Quality**: automated unit, integration and component testing with meaningful coverage
- 🏗️ **Architecture**: enterprise applications, monorepos, reusable packages and scalable frontend systems
- 🔄 **Delivery**: CI/CD, automated pipelines, release workflows and deployment automation
- ☁️ **Infrastructure**: AWS, Docker, Linux and bare-metal environments
- 🚀 **Product thinking**: MVPs, rapid iteration and turning ideas into usable products

## 🤖 AI & agentic development

I use **AI coding tools, Claude, Claude Code and coding agents** as part of my engineering workflow.

I am interested in agentic coding as a **human + agent collaboration**, not autonomous code generation.

```text
Human defines context + constraints
              ↓
        AI explores code
              ↓
       Agent implements
              ↓
       Tests + iteration
              ↓
Human reviews behaviour + trade-offs
              ↓
             Ship
```

The interesting part is not simply writing code faster. It is learning how to give an agent the right **context, architecture, constraints and feedback** to work effectively inside a real codebase.
